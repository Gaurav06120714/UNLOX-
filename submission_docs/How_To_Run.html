Section 2 — Prerequisites

macOS Only — Install OpenMP runtime for XGBoost:

XGBoost requires the OpenMP library on Mac. Run this once before setup:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install libomp

Windows and Linux users can skip this step. libomp ships with XGBoost on those platforms.

Section 3 — Setup (One Command)

Step 1. Extract the source code zip file to your preferred location.

Step 2. Open Terminal (Mac/Linux) or Command Prompt (Windows) and navigate into the project folder:

cd "MAJOR project"

Step 3. Run the automated setup script:

bash setup.sh

This script will automatically:

  • Create a Python virtual environment in venv/
  • Install all dependencies listed in requirements.txt
  • Create required folders: data/, models/, logs/, reports/

Step 4. Activate the virtual environment:

# macOS / Linux:
source venv/bin/activate

# Windows:
venv\Scripts\activate
Section 4 — API Key Setup (Optional)

The project runs fully without an API key using built-in realistic dummy data. This step is only needed to connect your own YouTube channel.

Step 1. Copy the environment template:

cp .env.example .env

Step 2. Open .env in any text editor and fill in your credentials:

YOUTUBE_API_KEY=your_api_key_here
YOUTUBE_CHANNEL_ID=your_channel_id_here

Step 3. To get a free YouTube Data API v3 key, visit console.cloud.google.com → APIs & Services → Enable YouTube Data API v3 → Create Credentials → API Key.

Section 5 — Run the Full Pipeline

Run all 7 stages in sequence with one command:

python run_pipeline.py

Expected terminal output:

▶  Stage 2: Viral Score Engine
   Viral scores computed for 30 videos.
▶  Stage 3: Sentiment Analysis
   Sentiment labels assigned to 200 comments.
▶  Stage 4: A/B Testing
   4 A/B tests completed.
▶  Stage 5: Virality ML Model
   RMSE=11.19, R²=0.837, CV-R²=0.936±0.025
▶  Stage 6: Recommendation Engine

To run individual stages separately:

python run_pipeline.py --stage extract

python run_pipeline.py --stage sentiment
python run_pipeline.py --stage ab_test
python run_pipeline.py --stage virality
python run_pipeline.py --stage recommend

Section 7 — View the Auto-Generated HTML Report

After the pipeline runs, a self-contained HTML report is generated automatically:

reports/final_report.html

Double-click the file to open it in any browser. No server or internet connection is required. All charts are embedded directly inside the HTML file as base64 images.

Section 8 — Docker Deployment (Alternative Method)

If Docker Desktop is installed, run the entire project in a container:

# Build and launch:
docker compose up --build

# Then open: http://localhost:8501

# Stop when done:
docker compose down

Docker automatically installs all dependencies and runs the pipeline inside the container. No Python setup needed on the host machine.
