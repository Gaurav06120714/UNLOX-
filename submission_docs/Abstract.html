Problem Statement

Content creators and digital marketers lack a systematic, data-driven approach to understanding why certain content performs better than others. Decisions around posting time, content type, and topic selection are largely made on intuition rather than evidence. This results in inconsistent engagement, wasted effort, and missed growth opportunities on social media platforms.

Objective

To design and build a complete end-to-end Machine Learning analytics ecosystem that automatically collects social media performance data, applies statistical and ML models to extract actionable insights, and delivers strategy recommendations through a 9-page interactive dashboard — demonstrating the full data science lifecycle from ingestion to serving.

Modules Built
  • Module 1 — Content Performance Tracker: Automated data extraction via YouTube Data API v3. Fetches video metadata, engagement metrics, and audience comments. Stores structured data in CSV and SQLite database with a hybrid real + dummy data mode for development.
  • Module 2 — Viral Score Engine: Computes a 0–100 Viral Score per video using a weighted min-max normalisation formula across five engagement dimensions: views, likes, comments, like rate, and comment rate.
  • Module 3 — NLP Sentiment Analyser: TextBlob-based sentiment classification of audience comments into Positive, Neutral, and Negative categories with polarity scores (-1 to +1) and subjectivity scoring.
  • Module 4 — A/B Testing Framework: Statistical hypothesis testing using Welch's t-test (unequal variance), Cohen's d effect size measurement, and Lift % calculation across four content variables: posting time, video length, tag count, and description length.
  • Module 5 — Virality Prediction Model: XGBoost Regressor trained on 16 engineered features to predict viral score from video metadata. Achieved R² = 0.84 on test set and Cross-Validation R² = 0.94 ± 0.02 across 5 folds.
  • Module 6 — Content Recommender: TF-IDF vectorisation on top-quartile video titles extracts high-performing keywords. Generates 7 ranked, confidence-scored strategy recommendations with evidence-backed rationale.
  • Module 7 — Trend Forecaster: Facebook Prophet model with Holt-Winters ETS fallback for 90-day engagement forecasting with 80% confidence intervals, plus keyword trend velocity analysis (Rising / Falling / Stable).
